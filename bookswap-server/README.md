# 블라인드 북 스왑 설정 안내

화면은 GitHub Pages(`bookswap/`)에, 추천 저장과 배정은 진행자의 구글 시트(Apps Script)에서 처리합니다.
참여자는 계정 없이 링크만 열면 됩니다.

## 1. 구글 시트에 서버 코드 넣기 (진행자, 약 5분)

1. [sheets.new](https://sheets.new)로 새 구글 시트를 만들고 이름을 붙입니다. 예: `북 스왑`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 기본 코드(`function myFunction() { }`)를 **빈 화면이 될 때까지 모두 지운 뒤**, `Code.gs` 내용을 통째로 붙여넣고 저장(💾)합니다.
   - `myFunction` 안에 붙여넣으면 배포 후 `Script function not found: doGet` 오류가 납니다.
   - 저장 후 상단 함수 선택 목록에 `doGet`이 보이면 맞게 된 것입니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙️): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요.
   - 본인이 만든 스크립트라서 나오는 경고입니다.
6. 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 Claude에게 알려 주세요.
   - 이 URL을 `bookswap/config.js`에 넣으면 페이지가 동작합니다.

## 2. 진행하면서

- 시트를 새로 열면 파일 제목이 **블라인드 북 스왑**으로 바뀌고, 상단에 **북 스왑** 메뉴가 생깁니다.
- **추천** 탭에 누가 어떤 책을 추천했는지 쌓입니다.
  - 진행자만 볼 수 있으니 **시트는 공유하지 마세요.**
- 14명이 모두 저장하는 순간 **배정** 탭이 자동으로 채워지고, 참여자 화면에 받은 책이 보입니다.
  - 배정 탭 열: 자리, 받는 사람, 추천한 사람, 제목, 저자, 배정 시각
  - 책을 나눠줄 때 이 탭을 그대로 쓰면 됩니다.
- **북 스왑** 메뉴
  - 진행 현황 보기: 아직 추천하지 않은 사람 확인
  - 배정 다시 하기
  - 테스트 배정 미리보기 (더미 데이터): **테스트 추천**, **테스트 배정** 탭에 더미 14건과 배정 결과를 만듭니다.
    - 실제 탭과 참여자 화면에는 영향이 없습니다.
    - 누를 때마다 새로 섞입니다.
  - 테스트 탭 지우기
  - 전체 초기화
- 누가 다른 사람 자리에 잘못 저장했다면, **추천** 탭에서 그 행을 지우면 다시 입력할 수 있습니다.
- 명단은 `Code.gs` 맨 위 `ROSTER`에 있습니다.
  - 추천이 시작된 뒤에는 순서를 바꾸지 마세요.

## 코드를 고친 뒤 다시 배포하기

**배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 누릅니다.
"새 배포"를 누르면 주소가 바뀌어서 페이지와 연결이 끊어집니다.

## 알아둘 점

- 로그인이 없어서 이름 선택은 본인 확인이 아닙니다.
  - 이미 완료된 자리는 처음 저장한 브라우저만 수정할 수 있습니다.
  - 비어 있는 다른 사람 자리를 누가 먼저 고르는 것까지는 막을 수 없습니다.
- 배정 결과(누가 어떤 책을 받았는지)는 이름을 누르면 누구나 볼 수 있습니다. 누가 추천했는지는 드러나지 않습니다.
